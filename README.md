# Todo List App

A modern and intuitive task management application built with ReactJS and Tailwind CSS. It helps users organize their daily activities and manage tasks efficiently.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Delete all tasks
- Simple and user-friendly interface

## Technologies Used

- ReactJS
- Tailwind CSS
- JavaScript
- Vite

## Installation

1. Clone the repository:

```bash
git clone https://github.com/hamza-hamri/TODO-LIST-APP.git
```

2. Navigate to the project directory:

```bash
cd TODO-LIST-APP
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```
